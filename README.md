# AD 风险评估 · 演示网站

一个纯前端的阿尔茨海默病（AD）风险评估原型，包含**患者端**与**医护端**，并把「临床资料缺失」的处理策略做进了产品：不把插补值当作真实观测，关键生物标志物缺失时只输出风险区间，而不是一个假装精确的点估计。

> 演示模型：基于示例系数的 logistic 回归，未用真实数据训练，不构成医学诊断。

## 两端功能

**患者端**（3 步，约 3 分钟）

1. 基本信息：年龄、性别、受教育年限、家族史
2. 认知与检查：MMSE、MoCA、APOE ε4、海马体积、淀粉样蛋白 PET、血液 p-tau217（均可留空）；可选填 12 项实验室检查
3. 评估结果：5 年风险环、风险分层、可能范围、下一步建议、实验室提示、打印

**医护端**（左录入 / 右输出）

- 实时风险分层与 5 年风险
- 检查建议（按缺失项自动生成）
- 检查完成情况一览
- 缺失数据处理卡：逐项列出缺失变量、机制标签与处置策略，并显示数据完整度

**方法学**：顶栏「方法学」打开四步说明（判机制 → 四维评估 → 分层处置 → 验证报告）。

## 实验室筛查（新增）

按「常规可及、低成本、可干预」原则纳入 12 项：

| 组别 | 项目 |
|---|---|
| 血常规 | 白细胞计数、红细胞计数、红细胞压积、血红蛋白、血小板计数 |
| 代谢 | 空腹血糖、总胆固醇 TC、LDL-C |
| 甲状腺与营养 | TSH、维生素 B12、叶酸、同型半胱氨酸 |

- 患者端：折叠在「认知与检查」中，**可选填**，不填不影响主评估。
- 医护端：独立「实验室检查」卡片，录入后即时给出「偏高 / 偏低」提示与处理建议。
- 实验室检查用于排查**可逆原因**（B12 / 叶酸缺乏、甲状腺功能减退）与**血管危险因素**，不改变 AD 风险点估计，避免虚假精度。
- 缺失处理：按 MAR 处理，不做单点插补；B12、叶酸、TSH、同型半胱氨酸缺失时提示补查。

## 缺失数据策略（本演示）

| 类型 | 示例变量 | 处理 |
|---|---|---|
| 关键生物标志物（MNAR） | PET、p-tau217、APOE | 不做单点插补，按 MNAR 加宽风险区间 |
| 量表 / 影像（MAR） | MMSE、MoCA、海马体积 | MICE 多重插补提示（m=20），用其他变量辅助 |
| 实验室检查（MAR） | 血常规、血糖、血脂、TSH、B12、叶酸、Hcy | 不插补；关键项提示补查，其余低影响项忽略 |
| 低影响变量 | BMI、高血压、糖尿病、吸烟 | 直接删除，不参与模型、不插补 |

风险区间随关键变量缺失数量加宽，直观体现「缺失越多、结论越不确定」。

## 演示参数

在 URL 后追加参数可直接查看特定状态：

- `?demo=1`：患者端，中风险示例，直接到结果页
- `?demo=clinic`：医护端，高风险示例（PET 缺失）
- `?demo=low`：医护端，低风险、资料完整
- `?static=1`：关闭动画（便于截图或打印）
- `?method=1`：直接打开方法学弹窗
- `?labs=1`：展开患者端「实验室检查」
- `?step=2&labs=1`：直接进入患者端第 2 步并展开实验室检查
- `?tour=1`：自动演示模式（虚拟光标 + 字幕，用于录屏）

例如：`index.html?demo=clinic&static=1`
